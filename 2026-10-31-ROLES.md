# Roles: ElevenLabs entry

Several Claude sessions work on this repo at once, one per role, each in its own git worktree and branch.
Each role edits only the paths it owns, so pull requests rarely conflict.
Chosen idea: **Full Cast**, The Monkey's Paw as a ~5-minute abridged audio drama with 6 voices, SFX and
music, on a 10,000-credit budget. The contract between roles is `docs/2026-10-31-interface.md`.
Verify command: `bash scripts/check.sh` (spends no credits).
Placeholder stems for Surface and Proof: `python -m core.placeholders --out output/placeholder`.

| Role | Folder (worktree) | Branch | Owns |
| --- | --- | --- | --- |
| Core | `elevenlabs-project` | `feature/full-cast-core` | `core/`, its tests, `scripts/`, `docs/2026-10-31-interface.md` |
| Surface + Story | `elevenlabs-project-surface` | `feature/surface` | `web/` (UI and audio mix), `assets/`, `README.md`, `docs/demo-script.md`, `submission.md`, backup video |
| Proof | `elevenlabs-project-proof` | `feature/proof` | `evals/`, `results/`, eval tests |

## What each role does
- **Core:** the hard technical piece (for example the real-time audio pipeline). Writes `docs/2026-10-31-interface.md` first: inputs, outputs and file formats. Owns all ElevenLabs API calls, so token use stays in one place.
- **Surface:** the UI and the final audio mix. Uses cached or placeholder audio, never fresh API calls, until Core's pipeline is ready.
- **Story:** README, demo script, submission text, backup video.
- **Proof:** measurements such as latency (`latency_ms`), timing accuracy (`sync_error_ms`), tokens used per run and listener ratings. Commit the raw results.

## Rules
1. Edit only the paths your role owns. If you need a change elsewhere, ask the user to pass it to the owning role.
2. Only Core changes `docs/2026-10-31-interface.md`. Any change to it must be called out in the PR description.
3. Before opening a PR, run the project's verify command (recorded in `CLAUDE.md`) and paste the result into the PR.
4. Small PRs into `main`, every hour or two: `gh pr create --base main`. The user approves merges.
5. After a merge, the other roles update with `git fetch origin` then `git merge origin/main`.
6. Free ElevenLabs tokens are limited: cache every generated clip and reuse it.
7. `ELEVENLABS_API_KEY` stays in `.env`. Never commit it, print it, or send it to the browser.
